六、常用命令速查

命令 作用
npx hexo s 本地预览（localhost:4000）
npx hexo clean 清除缓存和生成的静态文件
npx hexo generate 生成静态文件（简写：npx hexo g）
npx hexo deploy 部署到 GitHub（简写：npx hexo d）
npx hexo new "文章标题" 新建文章
npx hexo new page "页面名" 新建页面

七、踩坑记录

1. Fluid 主题配置不生效

注意：_config.fluid.yml 只放自己覆盖的配置项，不需要复制整份默认配置。主题的默认配置在 node_modules/hexo-theme-fluid/_config.yml 中，站点级配置会合并覆盖。

2. 部署后页面空白

检查 _config.yml 中的 url 是否配置正确，GitHub Pages 的 url 格式为 https://用户名.github.io。

3. SSH 连接失败

确保使用 git@github.com:用户名/仓库名.git 格式（SSH），而不是 https://github.com/... 格式。

总结

Hexo + GitHub Pages 的组合非常适合个人博客：

  • ✅ 完全免费 — GitHub Pages 提供免费托管
  • ✅ Markdown 写作 — 专注内容而非排版
  • ✅ 静态站点 — 速度快、安全性高
  • ✅ 主题丰富 — Fluid 等优秀主题让博客颜值在线
