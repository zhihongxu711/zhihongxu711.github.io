Ubuntu 输入法与终端字体定制全记录

前言

最近终于受不了系统自带的 ibus-libpinyin 中文输入法，加上终端里显示中文一直很别扭——英文字体是漂亮的等宽，中文却回退成黑体，怎么调都不顺眼。于是花了一个晚上，把输入法和终端字体整体折腾了一遍。用的命令、写的配置、踩的坑，都整理在这篇里。

本文环境：Ubuntu（GNOME Wayland），内核 7.0.0-28-generic。

一、输入法：从 IBus 切换到 fcitx5

1. 诊断：问题不在”缺输入法”，而在”装好没用”

我一开始以为要装新输入法，结果一查发现，fcitx5 全家桶早就装好了（fcitx5、fcitx5-pinyin、fcitx5-chinese-addons，各种前端俱全），只是从来没启用过：

系统一直用的是 IBus + ibus-libpinyin，也就是我嫌弃的那个”自带输入法”。

二、终端字体：让中文也变好看

1. 我的需求

  • 英文：好看、适合写代码的等宽字体；
  • 中文：要楷体，看着舒服。

2. 初试三款编程字体

先装了 Fira Code / JetBrains Mono / Hack 三款经典编程等宽字体：

用 gsettings 即时切换对比（GNOME Terminal 默认 profile，换字体即时生效、不用重启）：

三款英文都很好看，但中文是硬伤——它们只有西文字形，中文回退到系统字体，风格完全不搭。

3. 关键认知：终端的中文靠 fontconfig 回退

等宽字体只管英文和符号，中文走的是 fontconfig 的回退链：主字体没有的字符，按顺序找下一个覆盖它的字体。所以要控制终端中文，就得动 fontconfig。

4. 一步步试字体

  • Noto Sans Mono CJK SC（系统自带，思源黑体等宽）：中英文同源、对齐整齐，但中文是黑体，不是我要的楷体；
  • Sarasa Mono SC（更纱黑体，GitHub 下载）：专为”代码 + 中文”设计，英文很棒，但中文还是黑体；
  • LXGW WenKai（霞鹜文楷，GitHub 下载）：开源楷体，观感最好，就是它了。

后两个装到用户目录（无需 sudo），下载自 GitHub Release：

5. 最终方案：英文 Sarasa + 中文文楷

想”英文用 Sarasa、中文用文楷”，核心难题是：Sarasa 本身也覆盖中文，直接拿它当主字体，中文会用它自己的黑体，文楷永远轮不到。

解法是在 ~/.config/fontconfig/fonts.conf 里做两件事：

  1. 挖掉 Sarasa 的中文字符范围（mode="assign" + <minus>），让 fontconfig 认为它不含中文；
  2. 在 Sarasa 的回退链里 append 文楷，中文字符就落到文楷。

6. 踩坑 1：fontconfig 读不到文楷的中文字符集

这是最诡异的一个坑。fc-scan / fc-match 读文楷的 charset 元数据时，显示它没有中文字符：

但用 fontTools 直接读字体文件，U+4E00（一）、U+4E2D（中） 全都在，cmap 映射了 4 万多字符——字体文件完全正常，是 fontconfig/FreeType 的元数据解析有 bug。

后果：不能用 fc-match 验证文楷有没有生效（它永远告诉你”回退到宋体”）。但实际终端渲染（VTE/Pango 直接走 FreeType 查字形）完全正常。验证文楷生效，直接看终端屏幕，别信命令行工具。

7. 踩坑 2：改完 fontconfig 要重启终端进程

gnome-terminal-server 对 fontconfig 有进程级缓存，改完配置后老终端不重读。需要重启：

重开后 claude --resume 回到会话继续。

三、破折号冲突：东亚”模糊宽度”字符

1. 现象

中文里常用的 ——（U+2014 破折号）在终端里和文字”打架”，显得错位、拥挤。

2. 原因

U+2014 属于东亚模糊宽度字符（East Asian Ambiguous），终端对它有两种处理：半角（1 格）或全角（2 格）。问题在于格子和字形宽度不一致：

  • 终端按半角给它 1 格；
  • 但 Sarasa / 文楷渲染的破折号字形是全角的；
  • 全角字形被硬塞进 1 格里 → 溢出，和相邻文字冲突。

3. 试过但否决的方案

把终端的模糊宽度整体设成全角（wide）：

破折号确实对齐了，但 ·、±、°、× 这类符号全部变成全角，英文场景下太宽，否决，改回 narrow。

4. 最终方案：符号交给窄字形字体渲染

保持 narrow（半角），把模糊标点从 Sarasa 和文楷的元数据里挖掉，再往 Sarasa 回退链里 append Hack（Hack 的破折号是窄字形），让这些符号统一用 Hack 渲染——字形宽度和格子宽度就一致了：

注意这里有个细节：fontconfig 会重新排序 append 的字体，不能依赖”append 顺序”，所以必须把文楷的模糊标点也挖掉，否则文楷会排在 Hack 前面抢走符号。

总结

这次用到的命令与配置文件：

输入法

  • im-config -n fcitx5 → 改写 ~/.xinputrc
  • 注销重登生效

终端字体

  • gsettings 改 profile 的 font、cjk-utf8-ambiguous-width
  • ~/.config/fontconfig/fonts.conf 做字体分工（挖字符范围 + 回退链 append）
  • 改完 killall gnome-terminal-server 或注销重登

值得记住的经验：

  • ✅ fcitx5 往往早就装好了，先查 im-config -m / pgrep，别急着装新的；
  • ✅ 终端中文由 fontconfig 回退链决定，改 fonts.conf 才能控制；
  • ✅ 让一个覆盖了中文的字体”让位”给另一个：用 <minus> 挖掉它的中文字符范围；
  • ✅ 东亚模糊宽度字符：要么字形宽度匹配格子宽度（narrow + 窄字形），要么统一全角，二选一；
  • ✅ fontconfig 元数据可能和真实字形不一致，以实际渲染为准。

以后换字体、换内核，照着这套配置改就行。
